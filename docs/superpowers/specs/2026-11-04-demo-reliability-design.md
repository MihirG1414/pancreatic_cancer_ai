## Specification and architecture

1. Fix reproduced Colab defects at their source. Set a noninteractive Matplotlib
   backend and disable generated bytecode for inference subprocesses. Baseline
   validation must reject tracked source changes and unexpected untracked code,
   while tolerating generated `.pyc` caches. No blanket dirty-source bypass.
2. Back up the executed notebook under ignored outputs. Restore nine ordered,
   cleared cells with a False default permission declaration, reliable input
   reuse messaging and self-contained download validation. Pin the notebook to
   the verified runtime-fix commit, never a moving branch. Keep diagnostics in
   captured console/stage logs. No model/environment changes in this milestone.
3. Fix display focus for a constant-valued candidate: choose the native k plane
   with the most positive map voxels, breaking ties by the earliest k. Select
   representative i/j planes from positive extents on that plane. All-zero maps
   use middle slices. Selection must never depend on dataset annotations.
4. Add an optional offline viewer to the existing report (`--interactive`).
   Stream native axis-2 slices to PNG assets; do not cache full source arrays.
   Embed metadata in the HTML so file:// works without fetch/CDNs/servers.
   Synchronized panels show CT, existing annotations and original candidate
   scores separately. Provide all k slices, candidate focus, common zoom,
   fill/outline/off and opacity. Explicit native direction/spacing and fixed
   display window; the viewer is not a standardized radiological workstation.
5. Candidate outlines bound only positive retained map support, not validated
   tumor contours. Never fabricate a smooth probability/attention heatmap from
   the constant candidate map. Preserve final maps and score. Include display
   selection statistics/provenance, no new diagnostic-performance claims.

## Risks, limits and acceptance

Offline PNG assets take disk/time; check memory/disk and bound supported export
size. Rendering stays one slice at a time and nearest-neighbor in browser; zoom
changes display only. Keep the original static report and previous artifacts.
Support no annotation and all-zero predictions. Explicit image-loading failure
and race protection prevent mixed-slice panels during fast navigation.

Tests: baseline caches vs source tampering, notebook syntax/cleared outputs and
