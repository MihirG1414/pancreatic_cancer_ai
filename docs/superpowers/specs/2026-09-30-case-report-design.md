# Milestone 2 CPU case report design

The milestone adds a local, read-only HTML report for one manifest case. It reuses `read_cases`, `load_volume`, `metadata`, `check_geometry`, `read_slice` and `plot_slice`. A command selects an exact case ID and a new output directory. It refuses an existing destination, bad geometry, malformed annotation values and missing files. It does not run a model.

For matching 3D annotations, walk native axis-2 planes once. Aggregate each label's voxel count and inclusive three-axis bounding box from slice coordinates. Count background too; show locations only for positive labels. Calculate mm³ and mL only for recognized spatial units and a valid affine, using the absolute 3×3 determinant to handle oblique or sheared geometry. Report unknown label IDs without guessing meanings. Use the verified MSD Task07 dictionary only when manifest source explicitly identifies MSD Task07; other cases show IDs without meanings. Describe all values as **dataset annotation measurements**.

Write one HTML file and three native-plane PNGs with overlays using the existing plotter. Choose the view center from label 2 if present, otherwise the first nonzero label, otherwise volume center. The report states voxel indices are zero-based, bounds inclusive, coordinates follow original NIfTI axes, and direction letters/world geometry come from the source affine. No resampling or file modification occurs. Escape case/source strings for HTML and omit private scan paths. Output remains ignored under `outputs/`. The report is local software inspection, not diagnosis or model performance.

Risks: compressed NIfTI reads cost time; one-slice streaming bounds arrays to a plane. Available RAM can be low; the existing slice budget refuses oversized views. Geometry checks can establish spatial compatibility but not patient identity. Native axis views require orientation care and are not standardized anatomical planes. Fail before creating outputs when geometry/labels are invalid; leave a clearly partial output directory if an I/O failure occurs while writing, with a rerun using a new name.
